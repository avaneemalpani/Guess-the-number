Guess-the-number-game
A python project

This is a two-player number guessing game developed in Python. One player secretly enters a number while the second player attempts to guess it within a limited number of attempts. The game provides hints after each guess and tracks remaining attempts.

Features
- Two-player gameplay
- Hidden secret number
- Limited guessing attempts
- High and low hints
- Replay functionality
- Input validation for incorrect entries

Technologies Used
- Python

Skills Demonstrated
- Loops and iteration
- Conditional statements
- Exception handling
- Function creation
- User interaction
- Game logic implementation

How to Run
1. Download the project files.
2. Open a terminal in the project directory.
3. Run:
Guess the number.py

Learning Outcomes
- Understand program flow
- User interactions
- Exception Handling
- Game development fundamentals
